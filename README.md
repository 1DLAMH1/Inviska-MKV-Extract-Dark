# Inviska MKV Extract - Custom Dark Mode Edition

A portable AppImage of Inviska MKV Extract v11.0, featuring custom enhancements for a better user experience.

![Inviska MKV Extract Dark Mode](screenshot-dark.png)

## ✨ Features
- 🌙 **Built-in Dark Mode**: Automatically applies a dark theme without needing to configure system settings.
- 🚀 **Updated MKVToolNix Tools**: Replaced the outdated bundled tools with the latest version for better compatibility and performance.
- 📦 **Fully Self-Contained**: Requires no additional libraries to run (only FUSE).

1. Download the AppImage file from the **[Releases](../../releases)** page.
2. Make it executable:
   ```bash
   chmod +x Inviska_MKV_Extract_v11.0_Dark.AppImage
   
   ./Inviska_MKV_Extract_v11.0_Dark.AppImage
